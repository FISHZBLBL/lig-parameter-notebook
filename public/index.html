使用说明

一行是一组加工参数。新组默认 3 件电学样品，每件测量 5 次，另 1 件留作表征/备用。先算每件均值，再按件等权平均。主表显示每件均值；点击后按“测量次数 × 样品”表格录入。空白不算 0，未全部测齐会标为暂均值。

同组表征/备用样品可在详情登记，不参与平均。断路、超量程或加工失败也在详情中选择，不用填写 0 代替。

筛选条件同时生效；“全部”表示该参数不限制。主表与地图使用实测mW，未测功率明确留空，设备百分比可在参数编辑中查看。

已确认旧版五格是同一件的五次读数：正常旧记录会转换为样品1的五次读数，样品2、3留空；转换前的读数、备注与状态保存在完整 JSON 的 measurementArchive 中。含异常状态的旧记录保留待核对。修改测量安排时，不能减少带有数据的样品或读数位置。

手机和电脑登录同一账号后共用云端记录。断网修改会缓存到此设备，恢复连接后重试；两台设备改了同一版本时会提示先备份再载入。定期下载 JSON 完整备份；导入备份会追加并重新编号，保留已有数据。演示数据单独查看并在导出中标识。

这里输入的是方阻 Ω/□，不会将电阻 Ω 自动换算成方阻。激光器端百分比、阵列百分比和实测功率分别保存。实测功率以 mW 输入、显示和导出，不按百分比推算。
